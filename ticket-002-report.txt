3. tunde:x:1001:1005:Teller, Front Desk:/home/tunde:/bin/bash
Explanation of the seven fields

Field 1 – Username

tunde is the user's login name used to sign in to the system.

Field 2 – Password Placeholder

x indicates that the encrypted password is stored securely in /etc/shadow instead of /etc/passwd.

Field 3 – User ID (UID)

1001 is Tunde's unique numerical user identifier.

Field 4 – Group ID (GID)
1005 is the numerical identifier of Tunde's primary group.

Field 5 – Comment (GECOS)

Teller, Front Desk describes the user's role or account information.

Field 6 – Home Directory

/home/tunde is the directory where Tunde's personal files are stored.

Field 7 – Login Shell

/bin/bash is the default command-line shell that starts after Tunde logs in.

The $y$ prefix indicates that Ubuntu is using the yescrypt hashing algorithm.

Members of the managers group can run commands as any user and any group.

9. Short Answers
a. Why are /etc/passwd and /etc/shadow two separate files instead of one?

The two files are separated to improve security. /etc/passwd stores general account information that many programs need to read, while /etc/shadow stores encrypted password hashes and can only be accessed by privileged users. Separating them helps protect user passwords from unauthorized access.

b. Why does the bank lock departed customers instead of deleting them?

Locking an account prevents the user from logging in while preserving important records such as files, user IDs, and ownership information. This is useful for audits, investigations, and maintaining accurate historical records without allowing further access to the account.

c. Why does the bank mandate sudo for managers instead of sharing the root password?

Using sudo allows managers to perform administrative tasks without knowing the root password. Every privileged command is logged with the user's identity, providing accountability and making it easier to audit system changes. Sharing the root password would remove this accountability and increase security risks.
